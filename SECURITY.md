# Security

Do not report security vulnerabilities through public GitHub Issues.

Use GitHub's private vulnerability reporting for this repository. Include the affected Viewer version, browser, file format, impact, and the smallest safe reproduction you can provide.

Never upload confidential customer documents, credentials, license tokens, private keys, or personal data to a public issue. A maintainer will provide a private transfer path when a source document is genuinely required.

General rendering and compatibility bugs belong in the public bug form.
