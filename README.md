# DocViewKit Viewer

Official compiled releases, online demo, and public issue tracker for DocViewKit Viewer.

- Install: `npm install @docviewkit/viewer`
- Online demo: https://docviewkit.github.io/viewer/
- Product site: https://docviewkit.com/
- Free license: https://docviewkit.com/portal/
- Releases: https://github.com/docviewkit/viewer/releases
- Bug reports: https://github.com/docviewkit/viewer/issues

This repository intentionally does not contain the product source code. Versioned compiled artifacts are published through GitHub Releases, npm, and GitHub Pages from the private DocViewKit release pipeline.

Without a valid license, documents continue to render with an English `DocViewKit — Unlicensed` watermark and a `Get a free license` link. A valid free license removes that watermark and retains the fixed DocViewKit brand.

Do not attach confidential documents to public issues. Follow [SECURITY.md](SECURITY.md) for security reports.
