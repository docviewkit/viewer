DOCVIEWKIT VIEWER · v__DOCVIEWKIT_VERSION__

Open Office, PDF and OFD files in your frontend application.

A frontend-local, read-only Viewer for browsers and compatible WebView hosts in Electron, Tauri, Ionic and Capacitor. Your document bytes stay on your device.

Lightweight document viewing with quick integration for everyday OA attachments, approval workflows, CRM/ERP systems, cloud drives, and enterprise SaaS or AI knowledge bases. Mount the Viewer and call open(file); format packs load on demand, with no conversion server to deploy.

Runtime compatibility

The Viewer runs in frontend environments that provide DOM/Custom Elements, module Workers, WebAssembly, Canvas/OffscreenCanvas, ImageBitmap, and FontFace. These include browsers and compatible WebView hosts in Electron, Tauri, Ionic and Capacitor. React Native and Flutter applications can embed it through a WebView that provides the same APIs; their native rendering layers do not run the Web Component directly. Validate the actual host engine, asset loading, CSP, fonts, and required interactions on each target platform.

Apache-2.0 open source

Viewer, Engine APIs and UI customization are available without runtime licenses or mandatory branding. Paid services cover support, customization and enterprise delivery.
